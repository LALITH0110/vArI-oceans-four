   ├─ No need to manually create it
   └─ OUTPUT_DIR.mkdir(exist_ok=True)

3. All documentation is optional
   ├─ Programs work without any .md files
   └─ Docs are for user reference only

4. Currently everything is in /mnt/user-data/outputs/
   ├─ This is fine for testing
   └─ Reorganize for distribution

5. Three files = working program
   ├─ ui.py
   ├─ drift_simulator.py
   └─ seeds.json
